## 🎀 Siyena's First Birthday – Interactive Digital Invitation

An elegant and interactive digital birthday invitation created to celebrate baby Siyena's first birthday.

This project features a beautiful pink angel-inspired theme with soft animations, personalized baby photographs, interactive elements, and a magical birthday experience. Guests can explore the invitation, view photographs, discover event details, and RSVP directly through WhatsApp.

## ✨ Features

- **Welcome Screen:** Beautiful introductory screen with a personalized photograph and an invitation button.
- **Angel Pink Theme:** Elegant blush pink, rose, white, and gold color palette.
- **Animated Hero Section:** Full-screen birthday introduction with smooth zoom effects.
- **Floating Animations:** Decorative floating feathers, balloons, and confetti effects.
- **Birthday Music:** Built-in birthday melody using the Web Audio API.
- **Interactive Birthday Cake:** Guests can interact with the cake and blow out the candle.
- **Photo Gallery:** Browse personalized birthday photographs with an interactive image viewer.
- **Event Information:** Display birthday date, time, venue, address, and dress code.
- **WhatsApp RSVP:** Allow guests to respond directly through WhatsApp.
- **Share Invitation:** Share the digital invitation with friends and family.
- **Responsive Design:** Optimized for desktop and mobile devices.
- **Accessibility:** Includes keyboard interaction and reduced-motion support.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Click the invitation button to explore the birthday invitation.

No additional installation or build process is required.

## ⚙️ Customization

Before publishing the invitation, update the event information in the JavaScript configuration:

```javascript
var D = {
    date: "Saturday, [Date]",
    time: "[Time]",
    place: "[Venue name]",
    addr: "[Address]",
    rsvp: "",
    dress: "Soft pink & white"
};
```

Update the following information:

- Birthday date
- Event time
- Venue name
- Venue address
- WhatsApp RSVP contact number
- Dress code

You can also replace the embedded photographs with your preferred birthday pictures.
